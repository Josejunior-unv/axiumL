Projeto 05 · Agente text-to-SQL com Claude

Cofre de Consultas

Como um agente responde perguntas em português consultando um banco SQLite: o laço de ferramentas com o Claude, as mensagens que vão para a API e as três camadas que impedem qualquer escrita.

  • barra escrita antes de rodarautorizador
  • recusa escrita no discoarquivo em mode=ro
  • interrompe consulta lentatempo limite de 5 s

    Os sete passos

    Tudo o que vem do banco é real: saídas das ferramentas, mensagens de erro e bloqueio, resultados das consultas, exportados por animacao/exportar_dados.py do projeto projetos-ia/05-agente-text-to-sql. As falas do modelo são um roteiro ilustrativo, porque a animação não chama a API.
